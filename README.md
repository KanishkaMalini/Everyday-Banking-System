# Everyday Banking

A React + Vite front-end banking system for a college project.

## Run the project

Open this folder in VS Code. Make sure the terminal is inside the folder that contains `package.json`.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173/`.

## Included features

- User registration and sign-in
- OTP verification step
- Account overview and balance display
- Deposit, withdrawal and transfers between registered users
- Utility bill payment form
- Transaction history and CSV statement export
- Profile page
- Responsive layout for desktop and mobile

## Demo note

The OTP for this front-end demonstration is `123456`. Each user must create their own account; no username or password is pre-filled.

This is a front-end academic demonstration. It does not connect to a real bank, send SMS messages, or process real payments. Account data is stored in the browser's local storage.
